# WatsonX.ai Content & Quiz Generation API

A FastAPI backend service that leverages IBM's WatsonX.ai to generate educational content and quizzes.

## Features

- Generate educational content on any topic
- Create multiple-choice questions based on the generated content
- RESTful API with OpenAPI documentation
- Docker containerization for easy deployment

## Setup

### Prerequisites

- Python 3.11+
- IBM Cloud account with WatsonX.ai access
- WatsonX API key and Project ID
